- **Licence:** the Datastore API returns **no licence field** for this dataset (`license_id` empty). Not the same as C8 (CC BY-SA). Ask GLA or treat as narrative-only under the Lead's 002 rule.

## 3. Child poverty and health — signals only

- **London:** Save the Children (March 2026) reports London's child poverty rate at 38%, highest English region; Tower Hamlets 50.3% (local authority).
